# Parcial-I

## Sistema Gestor de Ventas e Inventario (Mini-POS)

### Descripción

Aplicación de consola desarrollada en C# y .NET 8 para gestionar
productos, inventario y ventas de una tienda.

El sistema permite registrar productos, consultar el inventario,
registrar ventas, aplicar descuentos e IVA y consultar un reporte
de caja y estadísticas diarias.

### Tecnologías utilizadas

- C#
- .NET 8
- Aplicación de consola

### Funcionalidades

1. Registrar nuevos productos.
2. Consultar el inventario completo.
3. Registrar ventas.
4. Calcular descuento del 10% para clientes frecuentes.
5. Calcular IVA del 19%.
6. Actualizar automáticamente el stock.
7. Consultar el reporte de caja y estadísticas.
8. Validar los datos ingresados por el usuario.
